# Authentication & Tokens

The SNPI API supports two authentication mechanisms:

1. **User Authentication (JWT Bearer Tokens)**: For human users in the Next.js web application.
2. **Service Authentication (API Keys)**: For server-to-server background integrations, cron jobs, and partner systems.

---

## 1. User Authentication (JWT Flow)

### Step 1: Obtain an Access Token

Send user credentials to `POST /api/v1/identity/auth/login`:

<Tabs items={['cURL', 'JavaScript']}>
  <Tabs.Tab>
    ```bash
    curl -X POST "http://localhost:5000/api/v1/identity/auth/login" \
      -H "Content-Type: application/json" \
      -d '{
        "email": "<AUTHORIZED_USER_EMAIL>",
        "password": "<SECURE_AUTHENTICATION_CREDENTIAL>"
      }'
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```javascript
    const res = await fetch('http://localhost:5000/api/v1/identity/auth/login', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        email: '<AUTHORIZED_USER_EMAIL>',
        password: '<SECURE_AUTHENTICATION_CREDENTIAL>'
      })
    });
    const { accessToken, user } = await res.json();
    ```
  </Tabs.Tab>
</Tabs>

### Expected Login Response (`200 OK`)

```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "usr_01HXYZ789",
    "email": "<AUTHORIZED_USER_EMAIL>",
    "firstName": "Sokha",
    "lastName": "Chan",
    "roles": ["school_admin"],
    "primaryBranchId": "brn_phnom_penh_01"
  }
}
```

### Step 2: Use the Token in Requests

Attach the `Authorization: Bearer <accessToken>` header to every authenticated API call:

```http
GET /api/v1/student/students?limit=25 HTTP/1.1
Host: api.snpi.edu.kh
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Accept: application/json
```

---

## 2. Service Authentication (API Key Flow)

External systems and automated scripts authenticate using static, scoped API keys passed via the `X-API-Key` header:

```bash
curl -X GET "https://api.snpi.edu.kh/v1/student/students" \
  -H "X-API-Key: snp_live_9d8f3a1b7c..." \
  -H "Accept: application/json"
```

<Callout type="warning">
  API keys must be kept confidential and stored in server environment variables. Never commit API
  keys to client-side bundles or public GitHub repositories.
</Callout>
