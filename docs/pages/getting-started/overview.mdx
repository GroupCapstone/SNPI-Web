# Getting Started: Overview & Setup

This guide walks you through connecting your frontend application or integration script to the SNPI REST API.

---

## Base URLs

All API requests must be dispatched over HTTPS to the designated environment base URL:

| Environment           | Base URL                             | Description                                            |
| :-------------------- | :----------------------------------- | :----------------------------------------------------- |
| **Local Development** | `http://localhost:5000/api/v1`       | Local development server running on developer machine. |
| **Staging**           | `https://api-staging.snpi.edu.kh/v1` | Isolated testing environment with sanitized seed data. |
| **Production**        | `https://api.snpi.edu.kh/v1`         | Live production cluster with MongoDB replica set.      |

<Callout type="warning">
  Plaintext HTTP requests to production endpoints are automatically rejected with a `301 Moved
  Permanently` redirect to HTTPS.
</Callout>

---

## Quickstart: Your First Request

Verify that the API server is operational by hitting the public health check endpoint:

<Tabs items={['cURL', 'JavaScript (Fetch)', 'Python']}>
  <Tabs.Tab>
    ```bash
    curl -X GET "http://localhost:5000/health" \
      -H "Accept: application/json"
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```javascript
    const response = await fetch('http://localhost:5000/health', {
      headers: { 'Accept': 'application/json' }
    });
    const data = await response.json();
    console.log(data);
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```python
    import requests

    response = requests.get('http://localhost:5000/health')
    print(response.json())
    ```

  </Tabs.Tab>
</Tabs>

### Expected Response (`200 OK`)

```json
{
  "status": "healthy",
  "version": "1.0.0",
  "database": "connected",
  "replicaSet": "rs0",
  "uptime": 14205
}
```
