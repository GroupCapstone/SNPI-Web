# OWASP API Security Top 10 (2023) Defenses

The SNPI platform incorporates defense-in-depth measures against the **OWASP API Security Top 10 (2023)** benchmark.

---

## Defense Matrix

| OWASP Code     | Vulnerability           | SNPI Backend Implementation                                      | Verification Gate                                    |
| :------------- | :---------------------- | :--------------------------------------------------------------- | :--------------------------------------------------- |
| **API1:2023**  | **BOLA (IDOR)**         | Server-side query injection enforcing `schoolId` and `branchId`. | Direct ID query fails across tenant boundary.        |
| **API2:2023**  | **Broken Auth**         | RFC 8725 JWT validation, Argon2id passwords, IP rate-limiting.   | Brute force throttled after 5 failed attempts.       |
| **API3:2023**  | **BOPLA**               | Strict Zod schemas with `.strict()`, explicit response DTOs.     | Injected unapproved fields rejected with 422.        |
| **API4:2023**  | **Resource Exhaustion** | Strict pagination bounds (`limit <= 100`), 1MB body limit.       | Requests with `limit=1000` capped to 100.            |
| **API5:2023**  | **BFLA**                | Granular declarative `authorize(...)` middleware on all routes.  | Non-admin users attempting admin routes receive 403. |
| **API6:2023**  | **Business Flows**      | Multi-step transaction locks and idempotency keys.               | Duplicate submission blocked via idempotency.        |
| **API7:2023**  | **SSRF**                | Protocol whitelisting (`https:`) and private IP blocklist.       | Probing `169.254.169.254` or `127.0.0.1` blocked.    |
| **API8:2023**  | **Misconfiguration**    | Helmet security headers, CORS origin whitelisting, RFC 7807.     | Zero database stack traces leaked to client.         |
| **API9:2023**  | **Inventory Mgmt**      | Machine-generated OpenAPI contracts; sunset headers on v1.       | Unversioned or shadow routes blocked.                |
| **API10:2023** | **Unsafe Consumption**  | HMAC-SHA256 signature checks on inbound webhooks.                | Tampered webhooks rejected via `timingSafeEqual`.    |
