# Student Lifecycle API

The Student Lifecycle API manages student enrollment, demographic profiles, daily attendance, and campus branch transfers.

---

## 1. List Students (`GET /student/students`)

Retrieve a paginated collection of students scoped to your authorized branch.

### Query Parameters

| Parameter  | Type      | Default | Description                                                     |
| :--------- | :-------- | :------ | :-------------------------------------------------------------- |
| `page`     | `integer` | `1`     | Page number for offset pagination.                              |
| `limit`    | `integer` | `20`    | Number of items per page (Max: `100`).                          |
| `status`   | `string`  | -       | Filter by `active`, `suspended`, `graduated`, or `transferred`. |
| `branchId` | `string`  | -       | Filter by branch (Only permitted for `all_branches` scope).     |
| `search`   | `string`  | -       | Search by student name, code, or phone number.                  |

### Example Request

```bash
curl -X GET "https://api.snpi.edu.kh/v1/student/students?status=active&limit=2" \
  -H "Authorization: Bearer <JWT_ACCESS_TOKEN_SAMPLE>"
```

## 2. Create Student (`POST /student/students`)

Register a new student record. Enforces unique national identity and email validation.

### Request Body

```json
{
  "firstName": "Dara",
  "lastName": "Sok",
  "gender": "male",
  "dob": "2008-09-14",
  "email": "<AUTHORIZED_USER_EMAIL>",
  "phone": "+85512999888",
  "gradeLevel": 10,
  "branchId": "brn_phnom_penh_01"
}
```

### Response (`201 Created`)

```json
{
  "id": "std_01HXYZ103",
  "studentCode": "SNPI-2026-003",
  "firstName": "Dara",
  "lastName": "Sok",
  "status": "active",
  "createdAt": "2026-11-04T12:00:00.000Z"
}
```
